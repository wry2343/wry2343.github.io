Hermes Finance Tracker

A private personal-finance tool used by Codey Reece.

What it does

  • Reads selected Discovery Bank transaction alerts and supported grocery-receipt emails.
  • Uses read-only Gmail access.
  • Cannot send, delete, edit or move email.
  • Stores transaction and receipt records locally on the user's Mac.

Data handling

The application does not sell personal information, serve advertising, or upload finance records to a public database.
